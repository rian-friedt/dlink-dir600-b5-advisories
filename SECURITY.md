# Security Policy

## Coordinated disclosure

We practice coordinated disclosure. This repository contains security
research on the D-Link DIR-600 rev. B5 reported to the vendor on
2026-09-06/08; CVE IDs were requested from MITRE on 2026-09-15 and are
pending.

If you want to report an issue with the published research itself (e.g. an
error in an advisory), contact **rian.security@rian-friedt.de**.

## Scope of the published PoC material

The PoC code targets an owned laboratory device only. Do not use it against
devices without explicit permission.
